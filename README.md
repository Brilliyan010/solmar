SOLMAR is an open-world coastal-city game: drive 6 cars, dodge the cops, run 5 missions and beat 3 bosses — with a wanted system, minimap, economy, upgrades and save/load.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in your browser.
